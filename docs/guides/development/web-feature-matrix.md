# Web Migration Feature Matrix

This matrix tracks the primary Web app after the migration from Expo Web to `web/`.

| Area | Web Route / Surface | Status | Notes |
| --- | --- | --- | --- |
| Authentication | `/login`, `/register`, `/verify-email`, `/forgot-password`, `/invite/:code` | Implemented | Access token is memory-only; refresh uses HttpOnly cookie. |
| Organizations | `/organizations`, shell organization switcher | Implemented | Query keys include active organization where data is org-scoped. |
| Collaboration inbox | `/inbox`, `/conversations/:id` | Implemented | Desktop three-pane layout, mobile single-column detail behavior. |
| Messages and notes | Conversation workspace | Implemented | Chat events use cursor replay and dedupe. |
| Contacts | `/contacts` | Implemented | Contact profile fields and browser direct-call entry. |
| Follow-ups | `/follow-ups` | Implemented | Task list and completion controls. |
| Calls | `/calls`, call overlay | Implemented | Browser WebRTC direct-call engine with ticketed signaling. |
| Meetings | `/meetings`, `/meetings/:roomId/preflight`, `/meetings/:roomId` | Implemented | Browser media preview, device handling, join/leave, recording controls. |
| Recordings | `/recordings`, `/recordings/:recordingId` | Implemented | Download, transcription status, pagination, retry, segment deep link. |
| Agent Lab | `/agent-lab` | Implemented | ReAct and Workflow launch, trace, DAG, approvals, citations, history. |
| Knowledge center | `/knowledge` | Implemented | Text/URL/file import, versions, chunks, duplicates, source groups, dead letters. |
| Approvals | Agent Lab approvals tab | Implemented | Pending/all filter and approve/reject controls. |
| Citations | Agent Lab citations tab and transcript links | Implemented | Meeting transcript citations jump to recording transcript route. |
| Account security | `/settings/profile`, `/settings/password`, `/settings/sessions`, `/settings/blocked`, `/settings/legal`, `/settings/danger` | Implemented | Sessions, legal acceptance, blocks, account deletion. |
| Web Push | `/settings/notifications`, foreground toast, service worker | Implemented | Requires Firebase Web public config and backend FCM service account. |
| Billing | `/settings/billing` | Implemented | RevenueCat Web Billing entry; backend entitlements remain authoritative. |
| Localization | `/settings/preferences` | Implemented | Chinese default, English toggle available for shell strings. |
| Responsive layout | Desktop/tablet/mobile Playwright projects | Implemented | E2E covers core pages across all configured viewports. |
| Realtime translation | Hidden | Intentionally not primary | Backend code remains, but the Web migration does not expose it as a main path. |
| Transcript editing | None | Not implemented | Deferred to avoid versioning/audit model expansion. |
| Multi-node media scale-out | None | Not implemented | Beta target remains single media node and small meetings. |

## Verification

Current local gates:

```bash
cd web && npm run typecheck && npm run lint && npm test && npm run build && npx playwright test
cd desktop && npm run check
MYSQL_ROOT_PASSWORD=root MYSQL_PASSWORD=password REDIS_PASSWORD=redis JWT_SECRET=jwt MAIL_PASSWORD=mail TURN_HOST=turn.example.com TURN_REALM=turn.example.com TURN_USERNAME=turn TURN_PASSWORD=turn docker compose -f infra/docker-compose.production.yml config
docker build -f infra/Dockerfile.web -t allcallall-web .
```

The production Web image serves `web/dist` through Nginx. Runtime public config is generated by `infra/web-runtime-config.sh`.
