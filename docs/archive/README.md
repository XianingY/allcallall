# Documentation Archive

> **Archive status:** Historical material; not part of the maintained product documentation.

This directory preserves context that may be useful when reviewing the project's
history. Current product behavior and contributor guidance are indexed from
[`docs/README.md`](../README.md).

- `portfolio/` contains interview, demonstration, and resume-oriented material.
- `reports/` contains dated reviews, generated evaluations, and point-in-time measurements.
- `plans/` contains completed or superseded implementation and architecture plans.
