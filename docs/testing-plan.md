## 功能测试项

### 1. 邮箱验证流程
- [ ] 进入注册页面
- [ ] 输入邮箱地址
- [ ] 点击"发送验证码"按钮
- [ ] 检查后端日志是否有验证码生成记录
- [ ] 检查数据库是否保存了验证码记录
- [ ] 在验证码输入界面输入6位数字
- [ ] 点击"确认验证"按钮
- [ ] 检查验证是否成功

### 2. 用户注册流程
- [ ] 完成邮箱验证后自动跳转到注册页面
- [ ] 输入密码（至少8位）
- [ ] 输入显示名称
- [ ] 点击"注册"按钮
- [ ] 检查是否成功创建用户账户
- [ ] 检查是否自动登录

### 3. 用户登录流程
- [ ] 退出当前账户（如果已登录）
- [ ] 进入登录页面
- [ ] 输入邮箱和密码
- [ ] 点击"登录"按钮
- [ ] 检查是否成功登录并跳转到主页面

### 4. 联系人管理
- [ ] 进入联系人页面
- [ ] 添加新联系人
- [ ] 搜索联系人
- [ ] 检查联系人列表是否正确显示

### 5. 在线状态同步
- [ ] 检查用户在线状态是否正确显示
- [ ] 检查其他用户的在线状态是否同步更新

### 6. 音视频通话
- [ ] 选择一个在线联系人
- [ ] 发起音频通话
- [ ] 接受通话邀请
- [ ] 检查音频是否正常传输
- [ ] 结束通话
