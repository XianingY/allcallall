# 文档生成规则

## 触发条件
- 始终启用
- 自动应用

## 文档要求
1. **简洁性**：文档内容要简明扼要，突出重点
2. **存储位置**：所有文档统一存放在 `docs/` 目录下
3. **文档结构**：
   - 使用清晰的标题层级
   - 包含必要的代码示例
   - 添加适当的说明和注释

## 文档类型
- API 文档
- 使用指南
- 架构设计文档
- 配置说明文档

## 命名规范
- 使用小写字母和连字符：`feature-name.md`
- 使用有意义的文件名
- 保持文件名简短

## 示例路径
docs/
├── api/
├── guides/
├── architecture/
└── configuration/
