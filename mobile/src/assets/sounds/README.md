# 音频文件目录

本目录用于存放AllCallAll应用的音频文件。

## 文件列表

请将以下音频文件放置在此目录中：

- `incoming_call.mp3` - 来电铃声 (3-5秒)
- `ringback.mp3` - 回铃音 (2-3秒)

## 文件要求

- 格式：MP3 (推荐) 或 WAV
- 采样率：44100 Hz 或 48000 Hz
- 声道：单声道 (Mono)
- 比特率：64-128 kbps (MP3)
- 文件大小：建议小于 500KB

## 注意事项

1. 确保文件名完全匹配上述列表（使用.mp3扩展名）
2. 推荐使用MP3格式以减小文件大小
3. 如果文件缺失，应用仍可运行，但对应的音频将不会播放
4. 可以在应用设置中关闭音频提醒功能

更多信息请参考项目文档中的音频设置指南。
