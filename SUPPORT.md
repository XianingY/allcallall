# Support

AllCallAll is a community-maintained open-source project. Support is provided
on a best-effort basis without guaranteed response or resolution times.

## Where to Ask

- Use the bug report template for reproducible defects.
- Use the feature request template for product or design proposals.
- Use the documentation template for missing, unclear, or stale guidance.
- Include the affected commit, environment, logs with secrets removed, and the
  smallest reproduction you can provide.

Before opening an issue, check the [documentation index](docs/README.md),
[quick start](docs/getting-started/quick-start.md), and existing issues.

## What Not to Post Publicly

Do not include credentials, tokens, private messages, recordings, personal
data, production database contents, or security exploit details in an issue.
Report vulnerabilities privately using [SECURITY.md](SECURITY.md).

Project maintainers cannot provide private deployment operation, custom feature
development, or emergency production support through the public issue tracker.
